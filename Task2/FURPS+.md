| U   | Удобство использования (Usability)                                                                                                |                                                                                             |
| U1  | Интерфейс работы будет максимально удобным для клиента                                                                            |                                                                                             |
| U2  | Время отклика будет минимальным                                                                            |      Проведение НТ, возможно изменение архитектуры АБС                                                                                      |
| U3  | Придерживаться системы дизайна для приложений, которая принята в компании, использовать привычные цвета и брендированные элементы |                                                                                             |
| R   | Надёжность (Reliability)                                                                                                          |                                                                                             |
| R1  | Предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД             |                                                                                             |
| R2  | Cервисы должны работать 24/7 и быть доступны в 99,9% случаев                                                                      |                                                                                             |

| P   | Производительность (Performance)                                                                                                  |                                                                                             |

| P1  | Разработка возможности горизонтального масштабирования работы АБС                                                                                |                                                                                             |
| S   | Поддерживаемость (Supportability)                                                                                                 |                                                                                             |
| S1  | Использовать технологии, которые уже есть в банке                                                                                 |                                                                                             |
| S2  | Разработка технической документации                                                                                 |                                                                                             |
| +R  | + Ограничения (Restricitions)                                                                                                     |                                                                                             |
| R1  | Интернет банк и АБС должны быть слабо связаны, прямой обмен данными исключен                                                                  |                                                                                             |
| R2  | АБС может масштабироваться только вертикально из-за своей базы данных                                                             |                                                                                             |
| R3  | Нет возможности в доработке функционала подрядчика интернет-банка                                                             |                                                                                             |
| R4  | Нет возможности в доработке функционала подрядчика в парнерском колл центре                                                             |                                                                                             |
| R5  | Использовать технологии, которые в белом списке банка, например Kafka                                                                                 |                                                                                             |
